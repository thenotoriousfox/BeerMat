# Theme library sources

Themes BeerMat offers in the theme library (BeerMat Online) but doesn't ship in the apps. Each folder is a theme in
the same layout as `themes/` (themes/README.md); upload it from the admin console (Themes → Add a theme) and laptops
install it from Settings → Looks → Theme library.

The tests use these as real-world themes: they load them as a laptop's installed themes (my-themes/).
